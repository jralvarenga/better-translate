# RTL

`@better-translate/core` には RTL サポートが組み込まれています。
設定で右から左のロケールを宣言し、`getDirection` や `isRtl` でランタイムに方向を問い合わせます。

## 使うタイミング

アラビア語、ヘブライ語、ペルシア語、ウルドゥー語などの言語をサポートする必要があるときに RTL サポートを使います。
方向ヘルパーにより、別のルックアップ表なしで HTML 要素の `dir` 属性を型安全に設定できます。

## 方向の宣言

`configureTranslations` に `directions` キーを追加します。省略したロケールは `"ltr"` がデフォルトです。

```tsx showLineNumbers
import { configureTranslations } from "@better-translate/core";

const translator = await configureTranslations({
  availableLocales: ["en", "ar"] as const,
  defaultLocale: "en",
  messages: { en, ar },
  directions: {
    ar: "rtl",
  },
});
```

## 方向の問い合わせ

`getDirection` で任意のロケールの `"ltr"` または `"rtl"` を取得します。
`isRtl` は真偽値のショートハンドです。

```tsx showLineNumbers
translator.getDirection({ locale: "ar" }); // "rtl"
translator.getDirection({ locale: "en" }); // "ltr"

translator.isRtl({ locale: "ar" }); // true
translator.isRtl({ locale: "en" }); // false
```

## 呼び出しごとの上書き

`config.rtl` を渡すと、単一の呼び出しだけ設定済みの方向を上書きできます。
メッセージのルックアップには影響せず、解決される方向だけが変わります。

```tsx showLineNumbers
// RTL ロケールでも LTR を強制
translator.t("greeting", {
  locale: "ar",
  config: { rtl: false },
});

// LTR ロケールでも RTL を強制
translator.t("greeting", {
  locale: "en",
  config: { rtl: true },
});
```

## HTML への適用

ルート要素の `dir` 属性を描画するときは `getDirection` を使います。

```tsx showLineNumbers
// html 要素（例: Next.js のレイアウト）
<html lang={locale} dir={translator.getDirection({ locale })}>

// 特定のコンテナ
<div dir={translator.getDirection({ locale })}>
  {t("greeting")}
</div>
```
