# Astro

Astro アプリでリクエストを意識した翻訳が必要なときは `@better-translate/astro` を使います。

## 1. パッケージをインストールする

```sh
npm install @better-translate/core @better-translate/astro astro
```

## 2. トランスレーターを作る

`src/lib/i18n.ts` を作成します：

```ts
import { configureTranslations } from "@better-translate/core";

const en = {
  home: {
    title: "Hello from Astro",
  },
} as const;

const es = {
  home: {
    title: "Hola desde Astro",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es },
});
```

## 3. リクエスト設定を公開する

`src/lib/request.ts` を作成します：

```ts
import { getRequestConfig } from "@better-translate/astro";

import { translator } from "./i18n";

export const requestConfig = getRequestConfig(async () => ({
  translator,
}));
```

## 4. ミドルウェアでリクエストロケールを設定する

`src/middleware.ts` を作成します：

```ts
import { createBetterTranslateMiddleware } from "@better-translate/astro/middleware";

import { requestConfig } from "./lib/request";

export const onRequest = createBetterTranslateMiddleware(requestConfig, {
  resolveLocale: ({ params }) => params?.lang,
});
```

共有のブラケット形式一覧が必要なら、`@better-translate/astro` から `SUPPORTED_ASTRO_LOCALE_ROUTE_SYNTAXES` を import します。`[locale]`、`[lang]`、`[language]`、`[intl]`、`[i18n]`、`[l10n]`、`[localization]` が含まれます。

## 5. ページで翻訳を読む

`src/lib/server.ts` を作成します：

```ts
import { createServerHelpers } from "@better-translate/astro";

import { requestConfig } from "./request";

export const { getLocale, getTranslations } =
  createServerHelpers(requestConfig);
```

`src/pages/[lang]/index.astro` を作成します：

```astro
---
import { getLocale, getTranslations } from "../../lib/server";

const locale = await getLocale();
const t = await getTranslations();
---

<html lang={locale}>
  <body>
    <h1>{t("home.title")}</h1>
  </body>
</html>
```

## 任意の次のステップ

Astro のドキュメントやブログがローカライズされたコンテンツコレクションにある場合は、基本セットアップが動いたあとに Astro コンテンツヘルパーや MDX アダプターを追加します。

## ロケールファイルを自動生成する

すべての翻訳を手書きする代わりに、CLI で文字列を抽出しロケールファイルを生成できます：[CLI ガイド](/docs/cli)
