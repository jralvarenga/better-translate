# TanStack Router

TanStack Router または TanStack Start でロケール対応 URL が必要なときは `@better-translate/tanstack-router` を使います。

実際のアプリでは、多くの場合次と組み合わせます。

- トランスレーター用 `@better-translate/core`
- React コンポーネント内フック用 `@better-translate/react`

## 1. パッケージをインストールする

```sh
npm install @better-translate/core @better-translate/react @better-translate/tanstack-router
```

## 2. 共有トランスレーターを作る

`src/lib/i18n.ts` を作成します：

```ts
import { configureTranslations } from "@better-translate/core";

const en = {
  home: {
    title: "Hello from TanStack Router",
  },
} as const;

const es = {
  home: {
    title: "Hola desde TanStack Router",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es },
});
```

## 3. ロケールルーティング設定を追加する

`src/lib/routing.ts` を作成します：

```ts
import {
  defineRouting,
  SUPPORTED_TANSTACK_LOCALE_ROUTE_SYNTAXES,
} from "@better-translate/tanstack-router";

export const routing = defineRouting({
  defaultLocale: "en",
  locales: ["en", "es"] as const,
  routeTemplate: "/$lang",
});

console.log(SUPPORTED_TANSTACK_LOCALE_ROUTE_SYNTAXES);
```

## 4. ローカライズされたナビゲーションヘルパーを作る

`src/lib/navigation.tsx` を作成します：

```tsx
import {
  Link,
  useLocation,
  useNavigate,
  useRouter,
} from "@tanstack/react-router";

import { createNavigationFunctions } from "@better-translate/tanstack-router/navigation";

import { routing } from "./routing";

export const {
  Link: I18nLink,
  useLocale,
  useNavigate: useI18nNavigate,
  usePathname: useI18nPathname,
} = createNavigationFunctions({
  Link,
  routing,
  useLocation,
  useNavigate,
  useRouter,
});
```

必須のロケールセグメントには `routeTemplate: "/$lang"` または `routeTemplate: "/{$lang}"` を使います。デフォルトロケールでセグメントを省略する場合は `"/{-$lang}"` を使います。

サポートされるロケールパラメータ名は `@better-translate/core` 由来で、ここでは `SUPPORTED_TANSTACK_LOCALE_ROUTE_SYNTAXES` と必須・任意のサブセットとして公開されています。

## 5. React プロバイダーでアプリをラップする

`src/app.tsx` を作成します：

```tsx
import { RouterProvider } from "@tanstack/react-router";

import { BetterTranslateProvider } from "@better-translate/react";

import { router } from "./router";
import { translator } from "./lib/i18n";

export function App() {
  return (
    <BetterTranslateProvider translator={translator}>
      <RouterProvider router={router} />
    </BetterTranslateProvider>
  );
}
```

## 6. ロケール対応リンクと翻訳を使う

`src/components/header.tsx` を作成します：

```tsx
import { useTranslations } from "@better-translate/react";

import { translator } from "../lib/i18n";
import { I18nLink, useLocale } from "../lib/navigation";

export function Header() {
  const currentLocale = useLocale();
  const { t } = useTranslations<typeof translator>();

  return (
    <header>
      <h1>{t("home.title")}</h1>
      <I18nLink to="/" params={{ lang: currentLocale }}>
        Home
      </I18nLink>
    </header>
  );
}
```

## TanStack Start

TanStack Start を使う場合も、同じルーティングとナビゲーション設定を維持します。Next.js でリクエストヘルパーを追加するのと同様に、`@better-translate/tanstack-router/server` のサーバーヘルパーを追加します。

## ロケールファイルを自動生成する

すべての翻訳を手書きする代わりに、CLI で文字列を抽出しロケールファイルを生成できます：[CLI ガイド](/docs/cli)
