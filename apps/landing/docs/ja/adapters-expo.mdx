# Expo

Expo は Web の React と同じ React アダプターを使います。

現時点で `@better-translate/react-native` パッケージはありません。`@better-translate/react` は React Native の環境と開発体験を完全にサポートします。

## 実装

Expo アプリでも React アダプターの実装ガイドに従ってください：[React アダプター](/docs/adapters/react)

インストールコマンド、トランスレーターのセットアップ、プロバイダー、`useTranslations` API は同じです。Expo では、React ガイドが Web 向けファイルを使う箇所に、アプリの Expo エントリファイルと画面コンポーネントを置き換えてください。

## メンタルモデル

- `@better-translate/core` が翻訳データを所有する
- `@better-translate/react` が Expo にプロバイダーとフックを提供する

ほとんどの Expo アプリでは、これがセットアップの全体です。

## ロケールファイルを自動生成する

すべての翻訳を手書きする代わりに、CLI で文字列を抽出しロケールファイルを生成できます：[CLI ガイド](/docs/cli)
