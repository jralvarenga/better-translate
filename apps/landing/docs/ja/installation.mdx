# インストール

コアパッケージは、フレームワークやランタイムを問わず、あらゆる TypeScript プロジェクトで動作します。Next.js、React、Astro などのフレームワークを使う場合は、コアの上に対応するアダプターを追加できます。

## Core

```sh
npm install @better-translate/core
```

ほとんどのケースではこれだけで十分です。あらゆる TypeScript 環境で動作します。詳しくはこちら：[Core ガイド](/docs/adapters/core)

## Adapters

アダプターは、ロケール対応ルーティング、React のコンテキストとフック、リクエスト単位のヘルパーなど、フレームワーク固有のヘルパーをコアに追加する拡張です。コアを置き換えるのではなく、拡張します。

そのため、多くの実装ガイドはパッケージをまたいで似た流れになります。いずれも同じコアのトランスレーターから始まり、その上に薄いフレームワーク向けの層を載せます。

完全なコントロールを好む場合は、アダプターを使わず `@better-translate/core` だけでも構いません。翻訳の挙動は同じで、プロジェクトによってはコアのみの方がすっきりする場合もあります。

利用可能なアダプターはこちらで確認できます：[アダプター](/adapters)

## CLI

CLI は、ロケールファイル管理の手作業を減らす任意の開発ツールです。

主に次の 2 つを行います。

- **Extract** — コード内の `{ bt: true }` が付いた文字列をスキャンし、自動生成されたキーでソースロケールファイルに追加し、呼び出しをその場で書き換えます
- **Generate** — ソースロケールファイルを読み込み、AI モデルで他の各ロケール向けの翻訳版を生成します

```sh
npm install -D @better-translate/cli
```

gateway ベースの構成なら `@better-translate/cli` だけで十分です。`better-translate.config.ts` で Ollama のようなダイレクトモデルプロバイダーを import する場合は、`npm install -D ollama-ai-provider-v2` のように該当プロバイダーパッケージもインストールしてください。

`npx bt extract` や `npx bt generate` を実行する前に、`better-translate.config.ts` を作成してください。その後は、ローカルの Ollama モデルを含む任意の AI SDK プロバイダーモデルで CLI を使えます。
