# Next.js

App Router でロケール付き URL、サーバー側翻訳、ロケール対応ナビゲーションが必要なときは `@better-translate/nextjs` を使います。

クライアント側フックも必要なら、このセットアップに `@better-translate/react` を追加します。

## 1. パッケージをインストールする

```sh
npm install @better-translate/core @better-translate/nextjs
```

## 2. トランスレーターを作る

`src/lib/i18n/config.ts` を作成します：

```ts
import { configureTranslations } from "@better-translate/core";

const en = {
  home: {
    title: "Hello from Next.js",
  },
} as const;

const es = {
  home: {
    title: "Hola desde Next.js",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es },
});
```

## 3. ルーティングファイルを追加する

`src/lib/i18n/routing.ts` を作成します：

```ts
import {
  defineRouting,
  SUPPORTED_NEXTJS_LOCALE_ROUTE_SYNTAXES,
} from "@better-translate/nextjs";

export const routing = defineRouting({
  defaultLocale: "en",
  locales: ["en", "es"] as const,
  routeTemplate: "/[lang]",
});

console.log(SUPPORTED_NEXTJS_LOCALE_ROUTE_SYNTAXES);
```

Better Translate はロケールパラメータ名を core の共有サポート一覧に制限します。有効な例には `[locale]`、`[lang]`、`[language]`、`[intl]`、`[i18n]`、`[l10n]`、`[localization]` があります。

## 4. リクエストとサーバーヘルパーを追加する

`src/lib/i18n/request.ts` を作成します：

```ts
import { getRequestConfig } from "@better-translate/nextjs/server";

import { translator } from "./config";

export const requestConfig = getRequestConfig(async () => ({
  translator,
}));
```

`src/lib/i18n/server.ts` を作成します：

```ts
import { createServerHelpers } from "@better-translate/nextjs/server";

import { requestConfig } from "./request";

export const { getTranslations } = createServerHelpers(requestConfig);
```

## 5. ロケール対応ナビゲーションを追加する

`src/lib/i18n/navigation.ts` を作成します：

```tsx
"use client";

import Link from "next/link";
import { useParams, usePathname, useRouter } from "next/navigation";

import { createNavigationFunctions } from "@better-translate/nextjs/navigation";

import { routing } from "./routing";

export const {
  Link: I18nLink,
  usePathname: useI18nPathname,
  useRouter: useI18nRouter,
} = createNavigationFunctions({
  Link,
  routing,
  useParams,
  usePathname,
  useRouter,
});
```

## 6. プロキシを追加する

`src/proxy.ts` を作成します：

```ts
import { createProxy, getProxyMatcher } from "@better-translate/nextjs/proxy";

import { routing } from "./lib/i18n/routing";

export const proxy = createProxy(routing);

export const config = {
  matcher: getProxyMatcher(routing),
};
```

## 7. 翻訳付きページを描画する

`src/app/[lang]/page.tsx` を作成します：

```tsx
import { setRequestLocale } from "@better-translate/nextjs/server";

import { getTranslations } from "../../lib/i18n/server";

export default async function HomePage({
  params,
}: {
  params: Promise<{ lang: string }>;
}) {
  const { lang } = await params;

  setRequestLocale(lang);

  const t = await getTranslations();

  return <h1>{t("home.title")}</h1>;
}
```

## 8. ロケールを維持するリンクを追加する

`src/components/language-links.tsx` を作成します：

```tsx
"use client";

import { I18nLink } from "../lib/i18n/navigation";

export function LanguageLinks() {
  return (
    <nav>
      <I18nLink href="/" locale="en">
        English
      </I18nLink>
      {" | "}
      <I18nLink href="/" locale="es">
        Espanol
      </I18nLink>
    </nav>
  );
}
```

## React アダプターを追加するタイミング

クライアントコンポーネントで `useTranslations()` やプロバイダーが必要なときだけ `@better-translate/react` を追加します。

## ロケールファイルを自動生成する

すべての翻訳を手書きする代わりに、CLI で文字列を抽出しロケールファイルを生成できます：[CLI ガイド](/docs/cli)
