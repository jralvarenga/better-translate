# Core

`@better-translate/core` はあらゆる TypeScript プロジェクトで動作します。フレームワーク依存もランタイム要件もありません。Next.js、Astro、React、Bun、Node.js、スクリプト、その他の TypeScript 環境でも、同じ設定と同じ API です。

**アダプター**は、ロケール対応ルーティング、React コンテキスト、リクエスト単位のヘルパーなど、フレームワーク固有のヘルパーをコアに追加する拡張です。すべては同じコアの上に構築されています。

## コアを直接使う場合

フレームワーク固有のヘルパーが不要なときは、アダプターなしでコアを使います。サーバー、API、スクリプト、共有ライブラリ、またはセットアップ用アダプターがない TypeScript 環境が該当します。

## 1. パッケージをインストールする

```sh
npm install @better-translate/core
```

## 2. トランスレーターファイルを1つ作る

`src/i18n.ts` を作成します：

```ts
import { configureTranslations } from "@better-translate/core";

const en = {
  home: {
    title: "Hello",
    description: "This is the English version.",
  },
} as const;

const es = {
  home: {
    title: "Hola",
    description: "Esta es la version en espanol.",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es },
});
```

## 3. どこでもトランスレーターを使う

```ts
import { translator } from "./i18n";

translator.t("home.title"); // "Hello"
translator.t("home.title", { locale: "es" }); // "Hola"
translator.t("home.description", { locale: "es" });
```

## 4. あとからロケールを追加する

```ts
const fr = {
  home: {
    title: "Bonjour",
    description: "Ceci est la version francaise.",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es", "fr"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es, fr },
});
```

## フォールバックの挙動

アクティブなロケールにキーがなければ、better-translate はフォールバックロケールを試します。
フォールバックにもなければ、キー文字列そのものを返します。

- → ロケールの値がない → フォールバックロケールの値
- → フォールバックの値もない → キー文字列

## 非同期ローダー

プリロードしたくない言語用にロケールローダーを登録します。初回の読み込み成功後、ロード済みロケールはキャッシュされます。

```ts
const translator = await configureTranslations({
  availableLocales: ["en", "fr"] as const,
  defaultLocale: "en",
  messages: { en },
  loaders: {
    fr: async () => import("./messages/fr").then((m) => m.default),
  },
});

// 必要時に fr を読み込みキャッシュ
await translator.loadLocale("fr");
```

## 5. CLI で文字列を自動抽出する

キーを手で命名する代わりに、`{ bt: true }` で文字列をマークし、CLI に抽出とキー付けを任せます：

```ts
import { t } from "@better-translate/core";

// ソース文字列をそのまま書く — CLI が適切なキーに変換
t("Hello world", { bt: true });
```

`npx bt extract` で文字列をソースロケールファイルに同期し、呼び出しを適切なキーに書き換えます。完全なセットアップは [CLI ドキュメント](/docs/cli) を参照してください。
