# React

React コンポーネントで翻訳やロケール切り替えが必要なときは `@better-translate/react` を使います。

## 1. パッケージをインストールする

```sh
npm install @better-translate/core @better-translate/react
```

## 2. 共有トランスレーターを作る

`src/i18n.ts` を作成します：

```ts
import { configureTranslations } from "@better-translate/core";

const en = {
  home: {
    title: "Hello",
  },
} as const;

const es = {
  home: {
    title: "Hola",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es },
});
```

## 3. 型付きプロバイダー + フックのペアを作る

`useTranslations()` でキーとロケールの自動補完を得たいが、
ジェネリックの繰り返しや宣言ファイルを避けたい場合は、トランスレーターを一度だけ束ねます：

`src/i18n-react.ts` を作成します：

```ts
import { createBetterTranslateReact } from "@better-translate/react";

import { translator } from "./i18n";

export const { BetterTranslateProvider, useTranslations } =
  createBetterTranslateReact(translator);
```

## 4. アプリをラップする

`src/main.tsx` を作成または更新し、アプリローカルのプロバイダーを import します：

```tsx
import React from "react";
import ReactDOM from "react-dom/client";

import { App } from "./app";
import { BetterTranslateProvider } from "./i18n-react";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <BetterTranslateProvider>
      <App />
    </BetterTranslateProvider>
  </React.StrictMode>,
);
```

## 5. コンポーネント内で翻訳を読む

`src/header.tsx` を作成します：

```tsx
import { useTranslations } from "./i18n-react";

export function Header() {
  const { locale, setLocale, t } = useTranslations();

  return (
    <header>
      <h1>{t("home.title")}</h1>
      <button onClick={() => setLocale("en")} disabled={locale === "en"}>
        English
      </button>
      <button onClick={() => setLocale("es")} disabled={locale === "es"}>
        Espanol
      </button>
    </header>
  );
}
```

## React のみを使う場合

次の場合は `@better-translate/core` + `@better-translate/react` のみで足ります。

- React SPA
- Expo アプリ
- ロケール変更がクライアントコンポーネントで行われる

Next.js App Router の場合は、クライアントフック用にこのパッケージを残し、ルーティングとサーバーヘルパー用に Next.js アダプターを追加します。

## ロケールファイルを自動生成する

すべての翻訳を手書きする代わりに、CLI で文字列を抽出しロケールファイルを生成できます：[CLI ガイド](/docs/cli)
