# Astro

استخدم `@better-translate/astro` عندما يحتاج تطبيق Astro إلى ترجمات مدركة للطلب.

## 1. تثبيت الحزم

```sh
npm install @better-translate/core @better-translate/astro astro
```

## 2. إنشاء المترجم

أنشئ `src/lib/i18n.ts`:

```ts
import { configureTranslations } from "@better-translate/core";

const en = {
  home: {
    title: "Hello from Astro",
  },
} as const;

const es = {
  home: {
    title: "Hola desde Astro",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es },
});
```

## 3. تعريض إعداد الطلب

أنشئ `src/lib/request.ts`:

```ts
import { getRequestConfig } from "@better-translate/astro";

import { translator } from "./i18n";

export const requestConfig = getRequestConfig(async () => ({
  translator,
}));
```

## 4. تعيين إعداد الطلب المحلي في الوسيط

أنشئ `src/middleware.ts`:

```ts
import { createBetterTranslateMiddleware } from "@better-translate/astro/middleware";

import { requestConfig } from "./lib/request";

export const onRequest = createBetterTranslateMiddleware(requestConfig, {
  resolveLocale: ({ params }) => params?.lang,
});
```

إذا أردت القائمة المشتركة بصيغة الأقواس، استورد `SUPPORTED_ASTRO_LOCALE_ROUTE_SYNTAXES` من `@better-translate/astro`. تتضمن `[locale]` و`[lang]` و`[language]` و`[intl]` و`[i18n]` و`[l10n]` و`[localization]`.

## 5. قراءة الترجمات في صفحة

أنشئ `src/lib/server.ts`:

```ts
import { createServerHelpers } from "@better-translate/astro";

import { requestConfig } from "./request";

export const { getLocale, getTranslations } =
  createServerHelpers(requestConfig);
```

أنشئ `src/pages/[lang]/index.astro`:

```astro
---
import { getLocale, getTranslations } from "../../lib/server";

const locale = await getLocale();
const t = await getTranslations();
---

<html lang={locale}>
  <body>
    <h1>{t("home.title")}</h1>
  </body>
</html>
```

## خطوة اختيارية تالية

إذا كانت وثائق Astro أو مقالات المدونة في مجموعات محتوى مترجمة، أضف مساعدات محتوى Astro أو محول MDX بعد أن يعمل هذا الإعداد الأساسي.

## توليد ملفات الإعداد المحلي تلقائيًا

بدل كتابة كل ترجمة يدويًا، استخدم واجهة سطر الأوامر لاستخراج النصوص وتوليد ملفات الإعداد المحلي: [دليل واجهة سطر الأوامر](/docs/cli)
