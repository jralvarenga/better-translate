# RTL

يتضمن `@better-translate/core` دعم RTL مدمجًا.
تُعلن في الإعداد أي الإعدادات المحلية من اليمين إلى اليسار، ثم تستعلم عن الاتجاه
في وقت التشغيل باستخدام `getDirection` أو `isRtl`.

## متى تستخدمه

استخدم دعم RTL عندما يحتاج تطبيقك لغات مثل العربية أو العبرية أو الفارسية أو الأردية.
تمنحك مساعدات الاتجاه طريقة مكتوبة الأنواع لتعيين سمة `dir` على عناصر HTML
دون إدارة جدول بحث منفصل.

## إعلان الاتجاهات

أضف مفتاح `directions` إلى استدعاء `configureTranslations`. أي إعداد محلي تُهمله يكون افتراضيًا `"ltr"`.

```tsx showLineNumbers
import { configureTranslations } from "@better-translate/core";

const translator = await configureTranslations({
  availableLocales: ["en", "ar"] as const,
  defaultLocale: "en",
  messages: { en, ar },
  directions: {
    ar: "rtl",
  },
});
```

## الاستعلام عن الاتجاه

استدعِ `getDirection` للحصول على `"ltr"` أو `"rtl"` لأي إعداد محلي.
استدعِ `isRtl` للحصول على اختصار منطقي.

```tsx showLineNumbers
translator.getDirection({ locale: "ar" }); // "rtl"
translator.getDirection({ locale: "en" }); // "ltr"

translator.isRtl({ locale: "ar" }); // true
translator.isRtl({ locale: "en" }); // false
```

## تجاوز لكل استدعاء

مرّر `config.rtl` لتجاوز الاتجاه المُعدّ لاستدعاء واحد.
لا يؤثر ذلك على البحث عن الرسالة، بل يغيّر فقط الاتجاه المُحلَّ.

```tsx showLineNumbers
// فرض LTR حتى لإعداد محلي RTL
translator.t("greeting", {
  locale: "ar",
  config: { rtl: false },
});

// فرض RTL حتى لإعداد محلي LTR
translator.t("greeting", {
  locale: "en",
  config: { rtl: true },
});
```

## التطبيق على HTML

استخدم `getDirection` عند عرض سمة `dir` على العناصر الجذرية.

```tsx showLineNumbers
// على عنصر html (مثلًا في تخطيط Next.js)
<html lang={locale} dir={translator.getDirection({ locale })}>

// على حاوية محددة
<div dir={translator.getDirection({ locale })}>
  {t("greeting")}
</div>
```
