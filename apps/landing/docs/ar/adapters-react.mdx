# React

استخدم `@better-translate/react` عندما تحتاج مكونات React إلى الترجمة وتبديل الإعداد المحلي.

## 1. تثبيت الحزم

```sh
npm install @better-translate/core @better-translate/react
```

## 2. إنشاء المترجم المشترك

أنشئ `src/i18n.ts`:

```ts
import { configureTranslations } from "@better-translate/core";

const en = {
  home: {
    title: "Hello",
  },
} as const;

const es = {
  home: {
    title: "Hola",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es },
});
```

## 3. إنشاء زوج مزود + خطاف مكتوب الأنواع

إذا أردت أن يُكمل `useTranslations()` المفاتيح والإعدادات المحلية دون
تكرار الأنواع العامة أو إضافة ملف إعلان، اربط المترجم مرة واحدة:

أنشئ `src/i18n-react.ts`:

```ts
import { createBetterTranslateReact } from "@better-translate/react";

import { translator } from "./i18n";

export const { BetterTranslateProvider, useTranslations } =
  createBetterTranslateReact(translator);
```

## 4. تغليف التطبيق

أنشئ أو حدّث `src/main.tsx` لاستيراد المزود المحلي للتطبيق:

```tsx
import React from "react";
import ReactDOM from "react-dom/client";

import { App } from "./app";
import { BetterTranslateProvider } from "./i18n-react";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <BetterTranslateProvider>
      <App />
    </BetterTranslateProvider>
  </React.StrictMode>,
);
```

## 5. قراءة الترجمات داخل مكون

أنشئ `src/header.tsx`:

```tsx
import { useTranslations } from "./i18n-react";

export function Header() {
  const { locale, setLocale, t } = useTranslations();

  return (
    <header>
      <h1>{t("home.title")}</h1>
      <button onClick={() => setLocale("en")} disabled={locale === "en"}>
        English
      </button>
      <button onClick={() => setLocale("es")} disabled={locale === "es"}>
        Español
      </button>
    </header>
  );
}
```

## متى تستخدم React فقط

استخدم `@better-translate/core` + `@better-translate/react` فقط عندما:

- يكون تطبيقك React SPA
- يكون تطبيقك تطبيق Expo
- تحدث تغييرات الإعداد المحلي في مكونات العميل

إذا كنت في Next.js App Router، احتفظ بهذه الحزمة لخطافات العميل وأضف محول Next.js للتوجيه ومساعدات الخادم.

## توليد ملفات الإعداد المحلي تلقائيًا

بدل كتابة كل ترجمة يدويًا، استخدم واجهة سطر الأوامر لاستخراج النصوص وتوليد ملفات الإعداد المحلي: [دليل واجهة سطر الأوامر](/docs/cli)
