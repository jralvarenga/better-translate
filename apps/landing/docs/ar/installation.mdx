# التثبيت

تعمل الحزمة الأساسية في أي مشروع TypeScript، بغض النظر عن الإطار أو بيئة التشغيل. إذا كنت تستخدم إطارًا مثل Next.js أو React أو Astro، يمكنك إضافة المحول المطابق فوق الأساس.

## الحزمة الأساسية

```sh
npm install @better-translate/core
```

هذا كل ما تحتاجه في معظم الحالات. يعمل في أي بيئة TypeScript. اقرأ الدليل هنا: [دليل الأساس](/docs/adapters/core)

## المحولات

المحولات امتدادات للأساس تضيف مساعدات خاصة بالإطار: التوجيه المدرك للإعدادات المحلية، وسياق React والخطافات، ومساعدات لكل طلب، وغير ذلك. لا تحل محل الأساس، بل تمدّه.

لهذا تبدو معظم أدلة التنفيذ مألوفة عبر الحزم: كلها تبدأ من نفس المترجم الأساسي وتضيف طبقة رقيقة من راحة الإطار فوقه.

إذا فضّلت التحكم الكامل، يمكنك تخطي المحولات واستخدام `@better-translate/core` مباشرة. ستحصل على نفس سلوك الترجمة، وفي بعض المشاريع قد يكون المسار بالأساس فقط أنسب خيار.

يمكنك الاطلاع على المحولات المتاحة هنا: [رابط هنا]

## واجهة سطر الأوامر

واجهة سطر الأوامر أداة تطوير اختيارية تزيل العمل اليدوي في إدارة ملفات الإعدادات المحلية.

تقوم بأمرين:

- **استخراج** — تفحص الكود بحثًا عن النصوص المعلّمة بـ `{ bt: true }`، وتضيفها إلى ملف الإعداد المحلي المصدر بمفاتيح مُنشأة تلقائيًا، وتعيد كتابة الاستدعاءات في مكانها
- **توليد** — تقرأ ملف الإعداد المحلي المصدر وتستخدم نموذج ذكاء اصطناعي لإنتاج نسخ مترجمة لكل إعداد محلي آخر

```sh
npm install -D @better-translate/cli
```

لإعدادات gateway، يكفي `@better-translate/cli`. إذا كان `better-translate.config.ts` يستورد مزود نموذج مباشرًا مثل Ollama، ثبّت أيضًا حزمة المزود المناسبة، مثل `npm install -D ollama-ai-provider-v2`.

قبل تشغيل `npx bt extract` أو `npx bt generate`، أنشئ `better-translate.config.ts`. بعد ذلك تعمل واجهة سطر الأوامر مع أي نموذج من مزودي AI SDK، بما في ذلك نماذج Ollama المحلية.
