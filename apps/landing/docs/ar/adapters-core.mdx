# الأساس

`@better-translate/core` يعمل في أي مشروع TypeScript. بلا اعتماد على إطار، بلا متطلبات وقت تشغيل. نفس الإعداد ونفس واجهة API سواء كنت في Next.js أو Astro أو React أو Bun أو Node.js أو سكربت أو أي بيئة TypeScript أخرى.

**المحولات** امتدادات للأساس تضيف مساعدات خاصة بالإطار: التوجيه المدرك للإعدادات المحلية، وسياق React، ومساعدات لكل طلب، وغير ذلك. لكن كل شيء مبني على نفس الأساس.

## متى تستخدم الأساس مباشرة

استخدم الأساس دون محول عندما لا تحتاج مساعدات خاصة بالإطار. يشمل ذلك الخوادم وواجهات API والسكربتات والمكتبات المشتركة أو أي بيئة TypeScript لا يوجد لها محول.

## 1. تثبيت الحزمة

```sh
npm install @better-translate/core
```

## 2. إنشاء ملف مترجم واحد

أنشئ `src/i18n.ts`:

```ts
import { configureTranslations } from "@better-translate/core";

const en = {
  home: {
    title: "Hello",
    description: "This is the English version.",
  },
} as const;

const es = {
  home: {
    title: "Hola",
    description: "Esta es la version en espanol.",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es },
});
```

## 3. استخدام المترجم في أي مكان

```ts
import { translator } from "./i18n";

translator.t("home.title"); // "Hello"
translator.t("home.title", { locale: "es" }); // "Hola"
translator.t("home.description", { locale: "es" });
```

## 4. إضافة إعداد محلي لاحقًا

```ts
const fr = {
  home: {
    title: "Bonjour",
    description: "Ceci est la version francaise.",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es", "fr"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es, fr },
});
```

## سلوك الاحتياط

إذا لم يكن للإعداد المحلي النشط مفتاح، يجرب better-translate إعداد الاحتياط.
إذا لم يكن الاحتياط يحتويه أيضًا، يعيد سلسلة المفتاح نفسها.

- → قيمة ناقصة في الإعداد المحلي → قيمة إعداد الاحتياط
- → قيمة ناقصة في الاحتياط → سلسلة المفتاح

## محمّلات غير متزامنة

سجّل محمّلات الإعدادات المحلية للغات التي لا تريد تحميلها مسبقًا. تُخزَّن الإعدادات المحلية المحمّلة في الذاكرة المؤقتة بعد أول تحميل ناجح.

```ts
const translator = await configureTranslations({
  availableLocales: ["en", "fr"] as const,
  defaultLocale: "en",
  messages: { en },
  loaders: {
    fr: async () => import("./messages/fr").then((m) => m.default),
  },
});

// يحمّل fr عند الطلب ويخزّنه
await translator.loadLocale("fr");
```

## 5. استخراج النصوص تلقائيًا بواجهة سطر الأوامر

بدل تسمية المفاتيح يدويًا، علّم النصوص بـ `{ bt: true }` ودع واجهة سطر الأوامر تستخرجها وتُنشئ مفاتيحها:

```ts
import { t } from "@better-translate/core";

// اكتب النص المصدر مباشرة — واجهة سطر الأوامر تحوّله إلى مفتاح صحيح
t("Hello world", { bt: true });
```

شغّل `npx bt extract` لمزامنة النصوص في ملف الإعداد المحلي المصدر وإعادة كتابة الاستدعاءات إلى مفاتيح صحيحة. راجع [وثائق واجهة سطر الأوامر](/docs/cli) للإعداد الكامل.
