## الإصدارات

يتبع Better Translate الإصدارات الدلالية. تُدار جميع الحزم في المستودع الموحّد
معًا.

- **تصحيح** — إصلاح أخطاء، بلا تغييرات في واجهة API
- **ثانوي** — ميزات جديدة، متوافقة مع الإصدارات السابقة
- **رئيسي** — تغييرات كاسرة
