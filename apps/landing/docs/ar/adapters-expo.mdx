# Expo

Expo يستخدم نفس محوّل React المستخدم في React على الويب.

حاليًا لا توجد حزمة منفصلة `@better-translate/react-native`. `@better-translate/react` يدعم بيئة React Native وتجربة التطوير بالكامل.

## التنفيذ

اتبع دليل تنفيذ محوّل React لتطبيقات Expo أيضًا: [محوّل React](/docs/adapters/react).

نفس أمر التثبيت وإعداد المترجم والمزود وواجهة `useTranslations`. في Expo، استخدم ملف دخول Expo ومكونات الشاشة حيث يستخدم دليل React ملفات خاصة بالويب.

## النموذج الذهني

- `@better-translate/core` يملك بيانات الترجمة
- `@better-translate/react` يمنح Expo المزود والخطاف

هذا الإعداد الكامل لمعظم تطبيقات Expo.

## توليد ملفات الإعداد المحلي تلقائيًا

بدل كتابة كل ترجمة يدويًا، استخدم واجهة سطر الأوامر لاستخراج النصوص وتوليد ملفات الإعداد المحلي: [دليل واجهة سطر الأوامر](/docs/cli)
