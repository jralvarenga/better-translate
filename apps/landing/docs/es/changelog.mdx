## Versionado

Better Translate sigue versionado semántico. Todos los paquetes del monorepo se versionan
juntos.

- **Patch** — correcciones de errores, sin cambios de API
- **Minor** — nuevas funciones, compatibles hacia atrás
- **Major** — cambios incompatibles
