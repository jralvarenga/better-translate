# Expo

Expo usa el mismo adaptador React que React en web.

Por ahora no existe un paquete `@better-translate/react-native` aparte. `@better-translate/react` admite por completo el entorno y la experiencia de desarrollo de React Native.

## Implementación

Sigue la guía de implementación del adaptador React también en apps Expo: [Adaptador React](/docs/adapters/react).

El mismo comando de instalación, configuración del traductor, provider y API `useTranslations` aplican. En Expo, usa el archivo de entrada de Expo y los componentes de pantalla donde la guía de React usa archivos específicos de web.

## Modelo mental

- `@better-translate/core` es dueño de los datos de traducción
- `@better-translate/react` aporta el provider y el hook a Expo

Esa es la configuración completa para la mayoría de apps Expo.

## Generar archivos de locale automáticamente

En lugar de escribir cada traducción a mano, usa la CLI para extraer cadenas y generar archivos de locale: [Guía de la CLI](/docs/cli)
