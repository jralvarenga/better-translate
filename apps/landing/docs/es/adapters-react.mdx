# React

Usa `@better-translate/react` cuando los componentes React necesiten traducciones y cambio de locale.

## 1. Instalar los paquetes

```sh
npm install @better-translate/core @better-translate/react
```

## 2. Crear el traductor compartido

Crea `src/i18n.ts`:

```ts
import { configureTranslations } from "@better-translate/core";

const en = {
  home: {
    title: "Hello",
  },
} as const;

const es = {
  home: {
    title: "Hola",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es },
});
```

## 3. Crear un par provider + hook tipado

Si quieres que `useTranslations()` autocomplete claves y locales sin
repetir genéricos ni añadir un archivo de declaración, enlaza tu traductor una vez:

Crea `src/i18n-react.ts`:

```ts
import { createBetterTranslateReact } from "@better-translate/react";

import { translator } from "./i18n";

export const { BetterTranslateProvider, useTranslations } =
  createBetterTranslateReact(translator);
```

## 4. Envolver tu app

Crea o actualiza `src/main.tsx` para importar el provider local de la app:

```tsx
import React from "react";
import ReactDOM from "react-dom/client";

import { App } from "./app";
import { BetterTranslateProvider } from "./i18n-react";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <BetterTranslateProvider>
      <App />
    </BetterTranslateProvider>
  </React.StrictMode>,
);
```

## 5. Leer traducciones dentro de un componente

Crea `src/header.tsx`:

```tsx
import { useTranslations } from "./i18n-react";

export function Header() {
  const { locale, setLocale, t } = useTranslations();

  return (
    <header>
      <h1>{t("home.title")}</h1>
      <button onClick={() => setLocale("en")} disabled={locale === "en"}>
        English
      </button>
      <button onClick={() => setLocale("es")} disabled={locale === "es"}>
        Espanol
      </button>
    </header>
  );
}
```

## Cuándo usar solo React

Usa solo `@better-translate/core` + `@better-translate/react` cuando:

- tu app es una SPA React
- tu app es una app Expo
- los cambios de locale ocurren en componentes de cliente

Si usas Next.js App Router, conserva este paquete para hooks en cliente y añade el adaptador de Next.js para enrutamiento y helpers en servidor.

## Generar archivos de locale automáticamente

En lugar de escribir cada traducción a mano, usa la CLI para extraer cadenas y generar archivos de locale: [Guía de la CLI](/docs/cli)
