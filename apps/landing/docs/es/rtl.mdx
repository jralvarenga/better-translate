# RTL

`@better-translate/core` incluye soporte RTL integrado.
Declaras qué locales son de derecha a izquierda en la configuración y consultas la dirección en runtime
con `getDirection` o `isRtl`.

## Cuándo usarlo

Usa el soporte RTL cuando tu app deba admitir idiomas como árabe, hebreo, persa o urdu.
Los helpers de dirección te dan una forma tipada de establecer el atributo `dir` en elementos HTML
sin mantener una tabla de búsqueda aparte.

## Declarar direcciones

Añade la clave `directions` a tu llamada `configureTranslations`. Cualquier locale que omitas usa `"ltr"` por defecto.

```tsx showLineNumbers
import { configureTranslations } from "@better-translate/core";

const translator = await configureTranslations({
  availableLocales: ["en", "ar"] as const,
  defaultLocale: "en",
  messages: { en, ar },
  directions: {
    ar: "rtl",
  },
});
```

## Consultar la dirección

Llama a `getDirection` para obtener `"ltr"` o `"rtl"` de cualquier locale.
Llama a `isRtl` para un atajo booleano.

```tsx showLineNumbers
translator.getDirection({ locale: "ar" }); // "rtl"
translator.getDirection({ locale: "en" }); // "ltr"

translator.isRtl({ locale: "ar" }); // true
translator.isRtl({ locale: "en" }); // false
```

## Sobrescritura por llamada

Pasa `config.rtl` para sobrescribir la dirección configurada en una sola llamada.
No afecta a la búsqueda del mensaje; solo cambia la dirección resuelta.

```tsx showLineNumbers
// Forzar LTR incluso en un locale RTL
translator.t("greeting", {
  locale: "ar",
  config: { rtl: false },
});

// Forzar RTL incluso en un locale LTR
translator.t("greeting", {
  locale: "en",
  config: { rtl: true },
});
```

## Aplicar en HTML

Usa `getDirection` al renderizar el atributo `dir` en elementos raíz.

```tsx showLineNumbers
// En el elemento html (p. ej. en un layout de Next.js)
<html lang={locale} dir={translator.getDirection({ locale })}>

// En un contenedor concreto
<div dir={translator.getDirection({ locale })}>
  {t("greeting")}
</div>
```
