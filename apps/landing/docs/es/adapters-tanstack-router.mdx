# TanStack Router

Usa `@better-translate/tanstack-router` cuando tu app use TanStack Router o TanStack Start y quieras URLs con locale.

En la mayoría de apps reales lo combinarás con:

- `@better-translate/core` para el traductor
- `@better-translate/react` para hooks dentro de componentes React

## 1. Instalar los paquetes

```sh
npm install @better-translate/core @better-translate/react @better-translate/tanstack-router
```

## 2. Crear el traductor compartido

Crea `src/lib/i18n.ts`:

```ts
import { configureTranslations } from "@better-translate/core";

const en = {
  home: {
    title: "Hello from TanStack Router",
  },
} as const;

const es = {
  home: {
    title: "Hola desde TanStack Router",
  },
} as const;

export const translator = await configureTranslations({
  availableLocales: ["en", "es"] as const,
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: { en, es },
});
```

## 3. Añadir la configuración de enrutamiento por locale

Crea `src/lib/routing.ts`:

```ts
import {
  defineRouting,
  SUPPORTED_TANSTACK_LOCALE_ROUTE_SYNTAXES,
} from "@better-translate/tanstack-router";

export const routing = defineRouting({
  defaultLocale: "en",
  locales: ["en", "es"] as const,
  routeTemplate: "/$lang",
});

console.log(SUPPORTED_TANSTACK_LOCALE_ROUTE_SYNTAXES);
```

## 4. Crear helpers de navegación localizados

Crea `src/lib/navigation.tsx`:

```tsx
import {
  Link,
  useLocation,
  useNavigate,
  useRouter,
} from "@tanstack/react-router";

import { createNavigationFunctions } from "@better-translate/tanstack-router/navigation";

import { routing } from "./routing";

export const {
  Link: I18nLink,
  useLocale,
  useNavigate: useI18nNavigate,
  usePathname: useI18nPathname,
} = createNavigationFunctions({
  Link,
  routing,
  useLocation,
  useNavigate,
  useRouter,
});
```

Usa `routeTemplate: "/$lang"` o `routeTemplate: "/{$lang}"` para segmentos de locale obligatorios. Usa `"/{-$lang}"` cuando el locale por defecto deba omitir el segmento.

Los nombres de parámetro de locale admitidos vienen de `@better-translate/core` y se exponen aquí como `SUPPORTED_TANSTACK_LOCALE_ROUTE_SYNTAXES` más los subconjuntos obligatorio y opcional.

## 5. Envolver la app con el provider de React

Crea `src/app.tsx`:

```tsx
import { RouterProvider } from "@tanstack/react-router";

import { BetterTranslateProvider } from "@better-translate/react";

import { router } from "./router";
import { translator } from "./lib/i18n";

export function App() {
  return (
    <BetterTranslateProvider translator={translator}>
      <RouterProvider router={router} />
    </BetterTranslateProvider>
  );
}
```

## 6. Usar enlaces con locale y traducciones

Crea `src/components/header.tsx`:

```tsx
import { useTranslations } from "@better-translate/react";

import { translator } from "../lib/i18n";
import { I18nLink, useLocale } from "../lib/navigation";

export function Header() {
  const currentLocale = useLocale();
  const { t } = useTranslations<typeof translator>();

  return (
    <header>
      <h1>{t("home.title")}</h1>
      <I18nLink to="/" params={{ lang: currentLocale }}>
        Home
      </I18nLink>
    </header>
  );
}
```

## TanStack Start

Si usas TanStack Start, mantén la misma configuración de enrutamiento y navegación. Luego añade los helpers de servidor de `@better-translate/tanstack-router/server` igual que añadirías helpers de petición en Next.js.

## Generar archivos de locale automáticamente

En lugar de escribir cada traducción a mano, usa la CLI para extraer cadenas y generar archivos de locale: [Guía de la CLI](/docs/cli)
